## 3. 본장표 구성: 요소 조합 (2026-11-19)

참고 장표(정본 덱, 모범 장표, 프레임 풀)는 장표 단위로 재현하지 않는다. 장표 안의 요소를 낱개로 골라 내용의 관계에 맞게 조합한다. 아래 기본형·카드형·Summary 장은 조합의 한 예시다.

### 조합 문법

```
장표 = 제목 + 영역 2개 (좌, 우)
영역 = ❏ 머리글 → 블록 1~3개 → 귀결
블록 = [블록 위 ● 요지] + 블록 제목·기준 표기 + (표 | 도식 | 박스) + [블록 아래 ● 귀결]
블록 사이 = 연결 장치 (회색 역삼각, ▼, 「특히,」 요지, → 귀결 줄)
```

1. 좌우 관계를 먼저 정한다: 대칭(같은 문법으로 효과 1 / 효과 2, 모범4) 또는 흐름(좌 진단 → 우 대응 모범5, 좌 현황 → 우 원인 정본 5/10).
2. 블록 하나는 관계 하나만 맡는다 (대비, 분해, 순서, 추적 등). 관계가 둘이면 블록을 나누고 연결 장치로 잇는다.
3. 요지 위치는 블록마다 고른다. 결론을 먼저 던질 블록은 위 요지, 숫자를 먼저 보이고 결론을 끌어낼 블록은 아래 귀결. 한 장 안에서 좌우가 달라도 된다 (모범6: 좌 위 요지, 우 아래 귀결).
4. 요지는 1~2줄. 2줄이면 「사실」 + 「귀결」 또는 ● + - 세부 + → 하위 귀결 묶음.
5. 귀결은 블록 결론(● 귀결, → 귀결 줄) 또는 영역·장 결론(회색 귀결 박스) 가운데 고른다. 모든 영역에 회색 박스를 둘 필요는 없다 (모범4 a는 박스 없이 ● 귀결로 닫음).
6. 좌우 최하단 y와 표 끝선을 맞춘다. 높이가 모자라면 블록을 추가하지 말고 행 높이와 박스 높이로 채운다.

### 조합 예시

기본형 (정본 5/10·6/10·8/10·9/10): 머리글 → ● 요지 → 기준 표기 → 표 → 회색 시사점 박스
대칭 2단 표형 (모범4 a): 머리글 → [ 구조 비교표 ] → ● 귀결 → ▽ → [ 시나리오 표 ] → ※ 가정 → ● 귀결 (좌우 같은 문법)
진단 → 대응형 (모범5): 좌 ● 요지 → 정성 불릿표 → → 귀결 줄 → ▽ → 단계 잔존 표 → ● 요지 + ● 「특히,」 / 우 ● 요지 → 같은 단계 축 대응표 → 회색 박스 (단계명) 접두 2줄)
카드형 (정본 7/10): 제목 → 전폭 ● 요지 2줄 → 2×2 카드 (라벨 칸 + 내용 칸)
Summary 장 (덱 끝 1장): 제목 「- Summary -」를 좌측 정렬 20pt 볼드(x 0.46, y 1.05, 밑줄 없음)로 쓰고, ■ 12pt 볼드 문단 5개 안팎(문단당 2~3줄, 본문 장 순서대로 한 문단씩). 괄호 부기는 10pt 보통, 핵심 구절은 남색 볼드.

결론은 한 곳에만 쓴다. 요지, 귀결, 회색 박스에 같은 문장을 반복하지 않는다. 회색 박스는 표가 말하는 사실에서 나온 귀결(→)을 적는다.

덱 구성(표지, Agenda, 첨부·참고자료 배치, 분량)은 산출 범위 밖. 본문에 담지 못한 세부 표는 발췌하지 않고 첨부 후보로 분리해 함께 전달.

## 4. 디자인 토큰

색: 본문 #000000 / 보충 글자 #595959 / 표 헤더·카드 라벨 면 #EBEFF5 / 회색 면 #F2F2F2 (귀결 박스, 합계·결론 행, 하위 증감 행, 표 안 설명 박스) / 선 #BFBFBF 0.5pt / 강조 남색 글자 #000099 / 빨간 밑줄 #FF0000 1.5pt / 도식 막대 진회색 #7F7F7F / 사진 캡션 바 #595959(기존)·#000066(최근)

타이포: 제목 20 볼드, 영역 머리글 14 볼드, 카드 라벨 12 볼드, ● 요지·①②③ 주항목·→ 귀결 11 볼드, 블록 제목 【 】 11 볼드 / [ ] 9 보통, - 세부 9~10, 표 헤더 10~11 볼드, 표 값 10, 셀 부기 9 회색, ※ 가정 9 회색, ex) 8 회색, 각주 8, Summary 문단 12 볼드

위계: ❏ 영역 머리글 → ● 요지 → ①②③ 주항목 / ➢ 사례 소제목 → - 세부 → → 귀결, ※ 보충, [분류] 접두. 장표 밖 보고 문구는 1. → 1) → -.

강조:
1. 검정 볼드: 표 1열, 핵심 값, 주항목
2. 굵은 검정 테두리 (1.5~2.25pt): 결론이 되는 범위를 셀 테두리로 감쌈. 단위는 열 1개(차이 열, 상한 열, 완료율 열), 열 묶음(개선 + 일정, 제휴 + 차이), 행 1개(결론 행), 표 1개(결과 표). 블록당 1곳
3. 빨간 밑줄: 핵심 수치와 귀결 구절 아래에 빨간 선 도형(#FF0000 1.5pt). 표 셀 값 아래에도 같은 방식. 글자 서식(underline)으로 넣지 않음. 영역당 2~4곳 기준, 블록마다 결론 값 1곳 + 귀결 구절 1곳을 넘기지 않음
4. 남색 볼드 (#000099): 문장 안 핵심 구절, 표의 대조되는 값(차이 열, 상한 열, 결론 행 값). 파란 계열은 이 남색 한 가지만 사용
5. 회색 면 (#F2F2F2, 테두리 없음): 귀결 박스, 합계·결론 행, 하위 증감 행

## 6. 문구 작성 원칙

1. 제목: 짧은 주제어, 결론 문장 금지 / 결론: 블록 위 ● 요지 또는 블록 아래 ● 귀결 (사실 → 귀결), → 귀결 줄, 회색 귀결 박스 가운데 한 곳, 같은 문장은 한 곳에만
2. 한 줄이 다음 줄과 같은 층위이거나 근거, 연결고리 없는 나열 금지
3. 개조식 명사형, 주어·목적어 생략 금지, 번역투·구어체 금지, 줄표 금지, 중점 나열 지양. 한자는 261026 덱에서 쓰는 관용 표기(內, 外, 比, 無, 限, 前, 高, 低, 非, 中)까지 허용, 영문은 유통 실무 용어(NB, ODM, POG, Vs. 등) 수준으로 사용
4. 사내 실제 메뉴명·자료명 사용, 신조어 금지, 낯선 고유명사는 속성 우선 + 괄호 병기, 기산점·대상 명시
5. 소스에 없는 수치·수식어·연결관계 금지(확인 필요), 검토 단계는 검토로 표기, 상관/인과 구분, 분류 순환성 명시, 표 라벨 중립 표현
6. 밀도: 근거는 많이, 문장은 짧게. 정보 밀도는 문장 수가 아니라 근거 수로 판단. ● 요지와 큰 글씨만 읽어도 장표 내용이 파악되어야 함
7. 미확인 표기: 장표 문구는 확인 필요, 수치 칸은 〔조사〕 또는 __, 채팅 답변은 검증 필요
8. 금지 어휘: 폭발적, 혁신적, 최고, 완벽, 최악, 반드시, 무조건, 절대로, 명백, ~해야함, 실패, 무효, 미미, 철회, ~소지

## 7. 지주 보고 독자 기준

디테일하되 쉽게, 사내 고유명사 풀이, 담당 조직(팀명) 서술 지양(주체 주어는 유지), 정보 밀도 확보, 모르는 수치는 〔조사〕/__ 표기, 범위가 다른 수치는 범위 병기, 내부 회의체 출처는 요청 없으면 미기재. 외부 사례를 근거로 쓸 때는 출처와 기준 시점을 적고, 사례 수치를 당사 효과로 옮겨 쓰지 않음.

## 8. 절차와 검수

적용 구분: 사용자가 기존 장표를 주고 수정을 요청하면 원안 구조를 존중하고 톤·문구만 보정. 새 장표를 만들 때만 아래 스토리보드 절차를 따름. 산출물은 요청 범위만 만들고, 추가 제안은 답변 끝에 한두 줄로.

스토리보드 = Claude가 평소 밀도로 만드는 슬라이드 한 장 분량의 초안. 초안 2~3장을 합쳐야 지주 보고 본장표 1장의 밀도가 나온다. 장표를 먼저 정해 놓고 스토리보드를 채우지 않는다.

절차:
1. 장표 목적 확인: 이 장이 답할 질문, 보고 대상, 활용 자료
2. 스토리보드 작성 (확산): 평소 밀도의 슬라이드 초안 2~3장 (장마다 리드, 본문, 근거를 갖춘 완결형), 근거는 원본 행·열·소속까지 대조
3. 본장표 구성 (수렴): 초안 리드를 묶는 장 요지 작성 → 초안 블록을 3장 조합 문법의 블록으로 배치(좌우 관계, 블록별 관계, 요지 위치, 연결 장치 결정) → 병합 → 기여하지 않는 블록 삭제 또는 첨부 후보 분리 → 매핑표 기록
4. 밀도화: 결합한 근거로 하단까지 충전, 강조 위치 지정

7. LibreOffice 렌더 검수 반복. 렌더 환경에는 맑은 고딕이 없어 글자 폭이 실제와 다르므로, 텍스트 폭·줄바꿈·밑줄 길이는 회사 PC(맑은 고딕) 기준으로 계산하고 5~10% 여유를 둠. 빨간 선 길이의 소폭 오차는 사용자가 조정
8. 산출 정리: 파일명 yymmdd_파일 이름_v.x.x.확장자 (yymmdd = 작성일. 단, 중요 보고 프로젝트 PPT 덱은 발표·보고일. 파일 이름 안 단어는 띄어쓰기, 보고 전 초안은 v.0.x, 보고 시 정수 상승), 만든 이 신호균(롯데마트-e사업전략팀)

스토리보드 초안 1장에 담을 내용: 초안 번호(SB-1~3)·가제목 / 답하는 질문 / 초안 리드(사실 → 귀결) / 본문(표·차트·박스, 프레임 1개) / 근거(파일명·시트·행열, 미확인은 확인 필요)

본장표 구성 기준:
1. 장 요지: 초안 리드 2~3개를 묶는 상위 메시지로 새로 작성 (나열 금지). ■ 리드를 두지 않으므로 영역 요지, 블록 귀결, 귀결 박스에 나눠 적음
2. 결합: 장 요지를 뒷받침하는 순서로 초안 본문 배치 (현황 → 원인 → 대책 등)
3. 병합: 결론이 같거나 같은 지표를 다루는 블록은 하나로
4. 삭제: 장 요지에 기여하지 않는 블록
5. 분리: 기여하지만 세부인 표는 첨부 후보로 분리해 함께 전달
6. 기록: 매핑표(초안 블록 → 결합 / 병합 / 삭제 / 첨부 후보 + 사유)
