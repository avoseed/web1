## 2. 판형과 공통 크롬

1. 슬라이드: A4 가로 27.52×19.05cm (sldSz type="A4")
2. 폰트: 맑은 고딕 단일 (python-pptx latin·ea·cs 3중 지정, Arial 대체 금지)
3. 여백: 좌·우·하단 1.5cm, 본문 폭 24.52cm (x 1.50~26.02), 콘텐츠 하한선 y 17.55
4. 그림자 없음 (p:style 제거 + 빈 effectLst)

※ 섹션 라벨, 페이지번호(우하단 n/N), 연결 탭은 덱 통합 시 사용자가 넣음. 본장표는 우하단 페이지번호 자리만 비워 둠.

제목 변형: 시리즈 장표는 검정 사각 번호박스, [향후 계획] 접두 허용, 부기는 괄호 소자 ('26.8.7 Open), [Back-up]은 좌측 정렬 + 전폭 밑줄.

## 3. 본장표 1장 구성

1. 제목 + 밑줄
2. ■ 리드: 이 장의 결론
3. 본문: 영역 구획(좌우 2단 등) + 영역별 프레임 1개
4. 각주

덱 구성(표지, Agenda, 첨부·참고자료 배치, 분량)은 산출 범위 밖. 본문에 담지 못한 세부 표는 발췌하지 않고 첨부 후보로 분리해 함께 전달.

## 4. 디자인 토큰

색: 본문 #000000 / 보충 #7F7F7F / 네이비 면 #1F3864 / 진네이비 #002060 / 명도 2·3단 #2E75B6·#9DC3E6 / 연회색 면 #F2F2F2 / 선 #BFBFBF 0.75pt / 빨강 #C00000 (장당 2~4곳)

타이포: 표지 36 볼드, 제목 20 볼드, 리드 14 볼드, 블록·컬럼 헤더 12~13 볼드, ● 주항목 11~12 볼드, 세부·표 10~11, 괄호 보충 본문-1pt 회색, 각주 8~9

위계: ■ 리드 → 【 블록 헤더 】/컬럼 헤더 → ● 주항목 → - 세부 → ①②③ 열거, → 귀결, ※ · * 주석. 장표 밖 보고 문구는 1. → 1) → -.

강조: 검정 볼드 1순위, 볼드 + 빨간 밑줄 장당 2~4곳, 회색 배경 박스·검정 사각 번호박스 허용. 금지: 형광펜, 빨간 테두리 박스, 빨간 개수 배지, 그림자, 은유형 도형. 파란 글자 기본 금지.

## 5. 표와 도식

표: 흰 셀 + #BFBFBF 0.75pt 4방 실선 / 헤더 볼드 가운데, 음영 #F2F2F2까지 / 전 셀 가운데, 재무 수치열 우측, 1열 볼드 / 1열 1개념 / 상위 분류 세로 병합 / 합계 행 볼드 + 상단 굵은 선 / 강조 행 연블루 + #002060 볼드 / 실적 종속 지표는 2단 헤더로 전 기간 표기

수치: 천단위 콤마, 소수 자릿수 통일 / 감소 ▲, 증가 +, %p / 원 수치 (보조지표) → 변경 수치 (보조지표), 증감률 (보조지표 변동폭) / 기간은 연도 포함 / 같은 지표 앞 장 중복 금지

도식: 논리 관계로 프레임 선택 (시장 진단 → 좌우 2단 차트, 시너지 → 3열 비교표, 테마별 효과 → 라벨×근거×효과, 개요 → 사진+제원표, 두 갈래 근거 → 좌우 2단 근거표, 단계 실행 → STEP 스택, 성과→계획 → 소표▶타임라인+카드, 기여 분해 → 워터폴, 이슈→개선 → [이슈]/[개선 경과], 실적 → 재무형 표)

기하: 컬럼 끝선 정렬, 블록 간격 0.50 통일, 좌우 2단 각 12.26cm·중앙선과 0.5cm 이상·최하단 y 일치·대칭, 하단 17.55까지 충전, 2줄 박스 문법 통일, 타임라인 확정=남색 점+실선/진행=흰 원+점선

## 8. 절차와 검수

스토리보드 = Claude가 평소 밀도로 만드는 슬라이드 한 장 분량의 초안. 초안 2~3장을 합쳐야 지주 보고 본장표 1장의 밀도가 나온다. 장표를 먼저 정해 놓고 스토리보드를 채우지 않는다.

절차:
1. 장표 목적 확인: 이 장이 답할 질문, 보고 대상, 활용 자료
2. 스토리보드 작성 (확산): 평소 밀도의 슬라이드 초안 2~3장 (장마다 리드, 본문, 근거를 갖춘 완결형), 근거는 원본 행·열·소속까지 대조
3. 본장표 구성 (수렴): 초안 리드를 묶는 장 리드 작성 → 초안 결합·병합 → 기여하지 않는 블록 삭제 또는 첨부 후보 분리 → 매핑표 기록
4. 밀도화: 결합한 근거로 하단까지 충전, 강조 위치 지정
5. 목업 승인
6. python-pptx 빌드
7. LibreOffice 렌더 검수 반복
8. 산출 정리: 파일명 원본 추출일, 만든 이 신호균(롯데마트-e사업전략팀)

스토리보드 초안 1장에 담을 내용: 초안 번호(SB-1~3)·가제목 / 답하는 질문 / 초안 리드(사실 → 귀결) / 본문(표·차트·박스, 프레임 1개) / 근거(파일명·시트·행열, 미확인은 확인 필요)

본장표 구성 기준:
1. 장 리드: 초안 리드 2~3개를 묶는 상위 메시지로 새로 작성 (나열 금지)
2. 결합: 장 리드를 뒷받침하는 순서로 초안 본문 배치 (현황 → 원인 → 대책 등)
3. 병합: 결론이 같거나 같은 지표를 다루는 블록은 하나로
4. 삭제: 장 리드에 기여하지 않는 블록
5. 분리: 기여하지만 세부인 표는 첨부 후보로 분리해 함께 전달
6. 기록: 매핑표(초안 블록 → 결합 / 병합 / 삭제 / 첨부 후보 + 사유)

체크리스트: 판형·폰트·그림자 / 제목·밑줄 / 리드가 초안 리드를 묶음 / 끝선 1.50·26.02, 하단 17.55 / 2단 대칭 / 표 규칙 / 팩트 / 금지 표현 / 강조 수 / 잘림 없음 / 9장 반복 지적 사항 자체 점검
