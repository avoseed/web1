## 0. 이 사전만 보지 않기 (출처 편중 방지)

1. 요소를 고를 때 순서: 이 장의 관계 판별 → 프레임 풀 관계 색인에서 F·E 후보 전체 → 그 안의 요소 → 이 사전으로 지주 양식 가공
2. 이 사전에 없는 요소도 관계에 맞으면 쓴다. 예: 2×2 매트릭스, 퍼널, 이슈 트리·드라이버 트리, 하비볼 평가표, 간트, 버블·산점도, 레이더, 상권 지도, 단면도, 미니 조직도, 받침·중괄호·× + 기호·캡슐 같은 구조 도형, 흐리게 다시 넣은 총괄표
3. 편중 점검: 한 장표의 요소가 모두 지주 샘플(정본 덱, 모범4~6)에서만 나왔으면 프레임 풀을 한 번 더 훑는다. 다시 봐도 지주 샘플 요소가 가장 맞으면 그대로 쓰고 이유를 한 줄 적는다
4. 반대로 외부 요소를 쓰더라도 서식은 지주 양식을 따른다 (색, 강조, 표 헤더, 그림자 없음, 은유형 도형 금지)

## 1. 조합 문법

장표 = 제목 + 영역 2개(좌, 우). 영역 = 머리글 → 블록 1~3개 → 귀결.

```
영역  : ❏ 머리글
        [요지]                       ← 선택 (블록 위 요지 또는 블록 아래 귀결 중 택일, 블록마다 다르게 써도 됨)
        블록 = [표 제목] + (표 | 도식 | 박스)
        연결자                        ← 블록이 2개 이상일 때 (역삼각, ▼, 「특히,」 요지, → 귀결 줄)
        블록 …
        귀결 = ● 요지 | → 귀결 줄 | 회색 박스
```

조합 규칙

1. 영역의 좌우 관계를 먼저 정한다: 대칭(같은 문법으로 효과 1 / 효과 2) 또는 흐름(좌 진단 → 우 대응, 좌 현황 → 우 원인).
2. 블록은 관계를 하나씩만 맡는다. 블록 하나에 비교와 추이를 함께 넣지 않는다.
3. 블록 사이 연결자는 관계를 말한다: 역삼각 = 앞 블록이 뒤 블록의 근거, 「특히,」 = 앞 결론의 하위 사례, ▼ = 단계 이동, → 귀결 줄 = 블록 결론.
4. 요지 위치는 고정이 아니다. 숫자를 먼저 보여야 설득되면 블록 아래 귀결, 결론을 먼저 던져야 하면 블록 위 요지 (카카오 ① 한 장 안에서 좌는 위, 우는 아래).
5. 좌우 최하단 y와 표 끝선은 맞춘다. 높이가 모자라면 블록을 추가하지 말고 행 높이와 박스 높이로 채운다.
6. 결론은 한 곳: 같은 문장을 요지와 귀결 박스에 반복하지 않는다. 귀결은 블록 결론, 회색 박스는 영역 또는 장 결론.
7. 장식은 마지막에 덜어낸다. 강조는 영역당 2~4곳.

## 4. 하지 않는 것

1. 참고 장표의 배치를 통째로 옮기기 (장표 단위 재현)
2. 블록 하나에 관계 두 개
3. 같은 결론을 요지와 박스에 반복
4. 큰 숫자 타일, 은유형 도형, 빨간 테두리, 형광펜, 그림자
5. 근거 없는 칸 채우기 (확인 필요 또는 〔조사〕로 표기)
