## 3. 본장표 1장 구성

기본형 (좌우 2단, 261026 덱 5/10·6/10·8/10·9/10):
1. 제목 + 밑줄
2. ❏ 영역 머리글 2개: 좌는 구조·현황 비교, 우는 상세 분석·원인·시사점처럼 좌에서 우로 읽히게
3. 영역마다 (● 요지 한 줄) → 기준 표기 → 표·도식 → 회색 시사점 박스
4. 각주 (필요할 때만)

카드형 (261026 덱 7/10): 제목 → 전폭 ● 요지 2줄 → 2×2 카드 (라벨 칸 + 내용 칸)

Summary 장 (덱 끝 1장): 제목 「- Summary -」를 좌측 정렬 20pt 볼드(x 0.46, y 1.05, 밑줄 없음)로 쓰고, ■ 12pt 볼드 문단 5개 안팎(문단당 2~3줄, 본문 장 순서대로 한 문단씩). 괄호 부기는 10pt 보통, 핵심 구절은 남색 볼드.

결론은 한 곳에만 쓴다. 영역 ● 요지와 시사점 박스에 같은 문장을 반복하지 않는다. 시사점 박스는 표가 말하는 사실에서 나온 귀결(→)을 적는다.

덱 구성(표지, Agenda, 첨부·참고자료 배치, 분량)은 산출 범위 밖. 본문에 담지 못한 세부 표는 발췌하지 않고 첨부 후보로 분리해 함께 전달.

## 8. 절차와 검수

적용 구분: 사용자가 기존 장표를 주고 수정을 요청하면 원안 구조를 존중하고 톤·문구만 보정. 새 장표를 만들 때만 아래 스토리보드 절차를 따름. 산출물은 요청 범위만 만들고, 추가 제안은 답변 끝에 한두 줄로.

스토리보드 = Claude가 평소 밀도로 만드는 슬라이드 한 장 분량의 초안. 초안 2~3장을 합쳐야 지주 보고 본장표 1장의 밀도가 나온다. 장표를 먼저 정해 놓고 스토리보드를 채우지 않는다.

절차:
1. 장표 목적 확인: 이 장이 답할 질문, 보고 대상, 활용 자료
2. 스토리보드 작성 (확산): 평소 밀도의 슬라이드 초안 2~3장 (장마다 리드, 본문, 근거를 갖춘 완결형), 근거는 원본 행·열·소속까지 대조
3. 본장표 구성 (수렴): 초안 리드를 묶는 장 요지 작성 (장표에는 영역 ● 요지와 시사점 박스 문구로 옮겨 적음) → 초안 결합·병합 → 기여하지 않는 블록 삭제 또는 첨부 후보 분리 → 매핑표 기록
4. 밀도화: 결합한 근거로 하단까지 충전, 강조 위치 지정
5. 목업 승인
6. python-pptx 빌드
7. LibreOffice 렌더 검수 반복. 렌더 환경에는 맑은 고딕이 없어 글자 폭이 실제와 다르므로, 텍스트 폭·줄바꿈·밑줄 길이는 회사 PC(맑은 고딕) 기준으로 계산하고 5~10% 여유를 둠. 빨간 선 길이의 소폭 오차는 사용자가 조정
8. 산출 정리: 파일명 yymmdd_파일 이름_v.x.x.확장자 (yymmdd = 작성일. 단, 중요 보고 프로젝트 PPT 덱은 발표·보고일. 파일 이름 안 단어는 띄어쓰기, 보고 전 초안은 v.0.x, 보고 시 정수 상승), 만든 이 신호균(롯데마트-e사업전략팀)

스토리보드 초안 1장에 담을 내용: 초안 번호(SB-1~3)·가제목 / 답하는 질문 / 초안 리드(사실 → 귀결) / 본문(표·차트·박스, 프레임 1개) / 근거(파일명·시트·행열, 미확인은 확인 필요)

본장표 구성 기준:
1. 장 요지: 초안 리드 2~3개를 묶는 상위 메시지로 새로 작성 (나열 금지). ■ 리드를 두지 않으므로 영역 ● 요지와 시사점 박스에 나눠 적음
2. 결합: 장 요지를 뒷받침하는 순서로 초안 본문 배치 (현황 → 원인 → 대책 등)
3. 병합: 결론이 같거나 같은 지표를 다루는 블록은 하나로
4. 삭제: 장 요지에 기여하지 않는 블록
5. 분리: 기여하지만 세부인 표는 첨부 후보로 분리해 함께 전달
6. 기록: 매핑표(초안 블록 → 결합 / 병합 / 삭제 / 첨부 후보 + 사유)
