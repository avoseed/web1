## 0. 공통 크롬 (전 본문 장표)

| 요소 | 규격 |
|---|---|
| **제목** | **가운데 정렬 + 제목 폭 밑줄**(굵은 실선). 시리즈 장표는 앞에 **검정 번호 사각박스**(`1`·`2`·`3`). 구분 프리픽스 `[향후 계획]`·`[Back-up]` 허용. 부제는 제목 뒤 작게 `('26.8.7 Open)` |
| **리드** | 제목 아래 **좌측** `■ ` + **볼드 한 줄**. 전 장표 필수 — **결론·요지를 여기서 못박는다**(하단 결론 박스 없음) |
| **각주** | 좌하단. 약어 정의는 `1) OSP : Ocado Smart Platform` 형식(위첨자 `1)` 과 대응). 출처·기준은 `* 출처 :` / `※ 기준 :` |
| **페이지** | 우하단 `n/12` |
| **백업 장표** | 제목 **좌측 정렬 + 전폭 밑줄**(본문형과 구분), `[Back-up]` 프리픽스 |

**블록 헤더**: `【 파트너십 추진 경과 】`·`【 차별화 설비 】` — 대괄호 장식 + 볼드.
**컬럼 헤더**: 가운데 볼드 + 하단 굵은 밑줄(선형) **또는** 연회색/연블루 채움 바(박스형).

**위계**: `● `(볼드 주항목) → `- `(세부) → `①②③`(열거) → `→ `(귀결·부연) → `※`·`*`(주석, 회색).
**강조**: **빨강** = 핵심 수치 밑줄(`38%`)·타원 콜아웃(`7,400건`)·배지(`CAGR +9%`)·강조 테두리.
**네이비 채움** = 라벨 박스·카드 헤더·표 헤더. **이탤릭** = 캡션(`- 전체 소매시장 중 온/오프 매출 구성비 (%) -`)·인용구·요약 스트립.
**회색 쉐브론(▶/》)** = 블록 간 전개 방향.

## 1. 본문 프레임 원형 (실측 12종)

### F1. 차트 2단 대비 (p1 · 시장 환경)
**논리**: 두 관점의 시장 진단(시장 변화 ↔ 경쟁 구도).
- 좌우 2단 + **중앙 세로 구분선**. 각 컬럼 = 컬럼 헤더(가운데+밑줄) → `● ` 소제목 → *이탤릭 캡션* → **차트**.
- 좌: 100% 누적 수평 바(연도별 온/오프 구성비) + 하단 요약 표(식품/비식품 CAGR).
- 우: 누적 컬럼 2개(연도 대비) + **우측 브래킷 그룹 라벨**(전용센터 67% 등) + **빨강 타원 CAGR 배지** + 증감 점선 연결.
- 자사 계열은 **검정 채움**으로 구분, 감소는 `▲9%p`.
> 쓸 때: 시장·경쟁을 수치로 진단하는 도입부. ✘ 정성 비교뿐이면 F3.

### F2. 강조 열 비교표 + 인용 + 경과 타임라인 (p2 · 추진 현황)
**논리**: 양자 역량의 결합(시너지) → 그 결합의 경과.
- **3열 비교표**(좌=상대 / **중앙=시너지** / 우=자사), 행 = `①②③④` **검정 번호박스 + 항목명**.
- **중앙 열 전체를 빨강 테두리로 감싸 강조**(파란 글자) — 이 열이 So-What.
- 표 아래 **이탤릭 볼드 인용구 한 줄**(`"…경쟁 우위 확보"`).
- 하단 `【 추진 경과 】` + **가로 타임라인**(굵은 축+화살촉, ○ 노드, 상단 회색 날짜 / 하단 라벨 2줄) +
  **점선 박스로 특정 구간 그룹핑**(`- 제타 스마트센터 오픈 준비 -`), 최종 노드는 ● 채움.
> 쓸 때: 파트너십·협업·결합 논리. ✘ 단순 우열 비교면 일반 비교표.

### F3. 라벨박스 × 근거 × 효과 3열 매트릭스 (p3 · 수익 기반)
**논리**: 테마별 [무엇을] → [어떻게] → [얼마나].
- 행 = 테마 3개, 행 사이 **점선 가로 구분**.
- 열 구성: ① **네이비 채움 라벨 박스**(고객경험 개선 / 수익성 확대 / 비용 최적화)
  ② `• ` 근거 불릿(부연은 **회색 괄호**) ③ **회색 쉐브론 ▶** → **효과 미니 표**(항목|값).
- 값 강조는 빨강 볼드(`17% → 29%`), 비교 첨자는 작게(`vs. 컬리 10.3%`).
> 쓸 때: 도입 효과·기대성과를 테마별로. ✘ 시간 순서면 F9.

### F4. 스펙 개요 (사진 + 제원표 + 설비 박스) (p4 · 센터 개요)
**논리**: 대상의 제원·특징 소개.
- 상단: **좌 사진 / 우 제원 표**(항목|값 2열, 일부 행은 4열 분할 `주차대수|480대`).
- 하단: `【 차별화 설비 】` + **연회색 채움 박스** 안에 `①②③` 항목(볼드 명칭 + 설명 + 괄호 부연).
- 약어는 위첨자 `1)` → 각주 정의.
> 쓸 때: 시설·조직·제품 개요 장표.

### F5. 우산 프로세스 + 깔때기 + 병렬 카드 (p5 · 차별화 Point)
**논리**: 공통 기반(우산) 위 프로세스 → 그 결과로 전달되는 가치.
- 상단: **점선 테두리 대형 박스** 안에 **연블루 우산 라벨**(`100% Cold Chain`) + 그 아래
  `①주문 → ②피/패킹 → ③배송` 흰 박스 + **회색 쉐브론**.
- 중간: **아래로 좁아지는 사다리꼴** + *이탤릭* `고객 전달 가치` — 위 프로세스가 아래 가치로 수렴.
- 하단: **3개 카드**(네이비 헤더 + 흰 본문 `● ` 볼드 → `- ` 세부), 카드 사이 쉐브론.
> 쓸 때: 기반→과정→고객가치 전개. ✘ 단순 3단 프로세스면 F5 상단만.

### F6. 좌우 2단 근거표 (p6 · 상품 경험)
**논리**: 두 축(확대 ↔ 구조 혁신)의 병렬 논증.
- 좌우 2단 + **연회색 헤더 바**(가운데 볼드) + 중앙 세로 구분선.
- 각 컬럼: `· ` 볼드(**핵심 구절 빨강 밑줄**) → `→ ` 부연 → `※`/`*` 주석 → **표**.
- 표: 지수 비교 행(`경쟁사 대비(Kurly Index=100)`) 포함, **핵심 셀 빨강 밑줄**(`38%`).
> 쓸 때: 두 갈래 실행 근거를 각각 표로.

### F7. 백업 2×2 사분면 (p7 · [Back-up] 공급구조)
**논리**: 4개 대상의 병렬 상세(참조용).
- 제목 **좌측 + 전폭 밑줄**. 화면을 **2×2로 4분할**.
- 각 사분면: **회색 라벨 박스**(대상명) → `· ` 볼드(회색 괄호 소재지) → `- ` 세부 → `①②③` →
  **사진 2~3장 + 캡션** 또는 **미니 표**.
> 쓸 때: 백업·부록의 대상별 상세.

### F8. 번호 구획형 (다이어그램 + 3구획) (p8 · 품질 가치)
**논리**: 하나의 주제를 `1. 2. 3.` 관점으로 나눠 각각 자기완결.
- 좌상: **평면·구조 다이어그램**(온도대별 색 구분: 상온 연파랑/냉장 연주황/냉동 진주황) +
  하단 **가로 타임라인**(입고→…→집 앞 배송, ○ 노드).
- 우상 `1. …` / 좌하 `2. …` / 우하 `3. …` — 각 **번호 소제목 + 밑줄** + `• ` 불릿 + 사진/예시 박스.
- 사진에 **점선 지시선(콜아웃)** 으로 부위별 라벨(`포장재 : 은박 에어캡`).
> 쓸 때: 한 주제의 다면 설명. **구획되어 있으므로 도식이 여러 개여도 몽타주 아님.**

### F9. 좌우 2단 + 이미지 근거 (p9 · 커버리지)
**논리**: 공간 확대(지도) ↔ 옵션 확대(UI 비교).
- 좌우 2단 + **연블루 헤더 바**. 각 컬럼 `①②③` 볼드 + `- ` 세부.
- 좌: **지도**(권역 노드 + `Direct`/`Spoke` 라벨 + 실선/점선 화살표).
- 우: **경쟁사 vs 자사 UI 스크린샷 비교**(캡션으로 차이 명시) + `》` 화살표.
> 쓸 때: 지리적 확대·화면 비교 등 이미지가 근거일 때.

### F10. STEP 세로 스택 + 행별 상세 (p10 · 마케팅)
**논리**: 단계별 실행 계획.
- 좌: **STEP 라벨 컬럼** — 3단 박스, **명도 그라데이션**(연회색 → 중간 파랑 → 진네이비)으로 진행감,
  박스 사이 **아래 방향 삼각 화살표**. 각 박스 = `STEP N` + 기간(`'26.7.14 ~ 8.14`).
- 우: 행별 2열 — `단계별 추진 방향`(볼드 + 회색 부연) | `Activity`(`• ` 볼드 + `Ex)` 예시).
- 컬럼 라벨은 표 헤더 없이 상단에 텍스트로.
> 쓸 때: 기간이 있는 단계 실행. ✘ 기여 분해면 F12.

### F11. 성과 → 계획 → 세부 카드 (p11 · 제휴 확대)
**논리**: 기존 성과를 근거로 향후 계획, 그리고 세부 실행.
- 상단 좌 `【 제휴 성과 】`(`● ` + **미니 표** + `※` 주석) → **회색 쉐브론** →
  상단 우 `【 향후 계획 】`(`● ` + **가로 타임라인**, 미래 구간은 **점선·페이드**).
- 하단 `【 세부 추진 방향 】` + **3개 카드**(네이비 헤더 + `● ` 본문 + **회색 하단 요약 스트립**(*이탤릭*)).
> 쓸 때: 성과 기반 확장 계획.

### F12. 워터폴 + 드라이버 그룹 매핑 (p12 · Road-Map) ★
**논리**: 목표까지의 기여 분해 — "무엇을 얼마나 더해 목표에 도달하는가".
- 중심 = **워터폴 차트**(기초 3,000건 → 증분 막대들 → 목표 7,400건 → 최종 12,000건).
  증분은 **명도 단계**로 그룹 구분, 최종 목표 막대는 **검정 채움** + *이탤릭* 라벨(`(오픈 1년차)`).
- 상단·중간에 **추진축 그룹 3개**(검정 번호박스 `1`·`2`·`3` + **네이비 헤더 2열 미니 표**: 세부 드라이버 | `+1,480건/일`) —
  각 그룹을 **점선으로 해당 막대에 연결**.
- 목표치는 **빨강 타원 콜아웃**. 막대 안 보조 지표(`가동률 19%`), 축 하단 카테고리 라벨.
> 쓸 때: 목표 달성 로드맵·증분 계획. **덱의 종착 장표 원형.**
